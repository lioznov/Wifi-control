# WIFI-control

Учебный проект на Python для просмотра открытых окон компьютеров класса. Состоит из панели преподавателя и видимого приложения ученика.

## Текущее состояние

Программы обмениваются списками заголовков окон через TCP. Панель показывает подключения и позволяет выбрать компьютер. Клиент периодически обновляет список, пока соединение работает.

Это учебная версия для теста на одном компьютере: сервер слушает только `127.0.0.1`, закрытие окон ещё не реализовано. Код доступа проверяется только на длину — программы не проверяют его совпадение. Обмен не шифруется. Не используйте эту версию для управления классом или в общей сети.

## Файлы

- `teacher.py` — панель преподавателя и TCP-сервер.
- `student.py` — окно ученика, поиск окон Windows и TCP-клиент.
- `requirements.txt` — внешние библиотеки Python.
- `.gitignore` — локальные файлы, которые не добавляются в Git.

## Установка в Windows

Требуются Python с tkinter и Git. Склонируйте репозиторий, затем в терминале папки проекта выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

В PyCharm выберите `.venv` в качестве интерпретатора проекта.

## Локальная проверка

1. Запустите `teacher.py`, введите код не короче 12 символов и нажмите «Запустить сервер».
2. Дождитесь сообщения «Сервер ожидает подключения...» в консоли.
3. На том же компьютере запустите `student.py`, введите `127.0.0.1` и код от 12 символов, затем нажмите «Подключиться».
4. Выберите подключение в панели преподавателя. Список окон будет периодически обновляться.

Введённые коды сейчас не сравниваются. Для проверки нескольких подключений можно запустить несколько экземпляров клиента; имя компьютера будет одинаковым, а порты различными.

## Как устроен обмен

Подробное описание функций и их связей находится в [ARCHITECTURE.md](ARCHITECTURE.md).

1. `show_open_windows()` собирает заголовки видимых окон Windows с простой фильтрацией.
2. `try_connection()` отправляет имя компьютера и список окон преподавателю в формате JSON через TCP.
3. `wait_for_students()` принимает подключения; `handle_student()` обрабатывает каждого клиента в отдельном потоке.
4. Серверные потоки передают события через очереди. `check_student_events()` и `check_presence_events()` обновляют состояние интерфейса в основном потоке.
5. `select_student()` и `show_selected_windows()` показывают окна выбранного соединения.

## Дальнейшая разработка

Запланированы проверка сторон и защита соединения, работа по локальной сети, выбор и закрытие окна, улучшение фильтрации и обработки отключений.
